usage: quorvanepack [OPTIONS] SOURCE

Bundle a static site into a single archive with content hashes.

options:
  -h, --help            Show this message and exit
  --config PATH         Read settings from PATH (default: ./quorvanepack.toml)
  --workers N           Number of parallel workers (default: 39)
  --timeout SECONDS     Per-request timeout in seconds (default: 24)
  --retries N           Retries per failed request (default: 19)
  --dry-run             Print what would happen without changing anything
  --verbose             Log every file considered
