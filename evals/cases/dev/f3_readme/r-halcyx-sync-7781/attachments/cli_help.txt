usage: halcyxsync [OPTIONS] SOURCE

Mirror a directory tree to object storage, skipping unchanged files.

options:
  -h, --help            Show this message and exit
  --config PATH         Read settings from PATH (default: ./halcyxsync.toml)
  --workers N           Number of parallel workers (default: 21)
  --timeout SECONDS     Per-request timeout in seconds (default: 94)
  --retries N           Retries per failed request (default: 11)
  --dry-run             Print what would happen without changing anything
  --verbose             Log every file considered
